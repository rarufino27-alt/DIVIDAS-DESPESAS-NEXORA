RAFLO FINANCE V1.18 — base visual minimalista + estrutura completa
Objetivo desta versão:
- manter as funções e módulos definidos para o NEXORA;
- aplicar a linguagem minimalista aprovada;
- renomear tudo para RAFLO FINANCE;
- manter Livro Caixa, Dívidas e Despesas, Receitas, Planejamento, Calendário, Relatórios e Configurações;
- pagamento recorrente NÃO é uma seção separada: é apenas o tipo de pagamento dentro do cadastro do compromisso;
- cartões, empréstimos e despesas continuam integrados em Dívidas e Despesas;
- a interface desta etapa é uma base de validação visual. A integração definitiva com Supabase deve preservar os contratos/tabelas existentes.
