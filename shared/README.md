# Contrato compartilhado RAQVOR

Desktop e Mobile usam o mesmo Supabase/workspace e o mesmo modelo lógico de dados.

A UI pode ser diferente; o dado não.

Princípios:
- uma fonte de verdade no Supabase;
- operações financeiras compostas devem manter rastreabilidade;
- IA interpreta, motor financeiro valida e o usuário confirma antes da execução;
- credor, cartão e compromisso permanecem entidades distinguíveis;
- ciclo financeiro é configuração de visualização/planejamento, não altera vencimentos reais.
