# Gestão financeira NEXORA — V1.9

Calendário financeiro operacional com visão mensal, semanas de segunda a domingo, semana atual destacada, saldo devedor semanal, receitas da semana, caixa, cálculo de diária restante e dias de folga configuráveis.

A diária é recalculada quando passa o dia, uma conta é paga, uma receita é recebida/cadastrada ou uma folga é marcada.
